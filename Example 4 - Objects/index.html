1. ობიექტის შექმნა

ობიექტი — key:value წყვილების კოლექცია. აღწერს "რამეს" მისი თვისებებით.

const student = {
  name:     "ანა ბერიძე",
  age:      17,
  school:   "TBC Tech School",
  isActive: true
};

2. Properties-ზე წვდომა

dot notation ან bracket notation. პროპერტის შეცვლა და დამატება.

student.name        // dot notation
student["age"]      // bracket notation
student.age  = 18;  // შეცვლა
student.city = "თბილისი"; // ახლის დამატება

3. მეთოდები ობიექტში

ობიექტი შეიძლება შეიცავდეს ფუნქციებსაც — მეთოდები.

const calculator = {
  value: 0,
  add(n)      { this.value += n; return this; },
  subtract(n) { this.value -= n; return this; },
  result()    { return this.value; }
};
calculator.add(10).add(5).subtract(3).result(); // 12

4. Object Destructuring

თვისებების ამოღება ახალ ცვლადებში სწრაფად.

const { name, age, school } = student;
console.log(name);   // "ანა ბერიძე"
console.log(age);    // 18
