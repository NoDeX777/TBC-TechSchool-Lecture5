### 📌 ნაბიჯი 1: პროექტის ჩონჩხის დაგენერირება
გახსენი AI (ChatGPT / Claude / Gemini) და მიწერე პირველი პრომპტი:

> **📋 PROMPT #1 (HTML + Tailwind):**
> *"შექმენი სუფთა და თანამედროვე ერთგვერდიანი ვებ-აპლიკაციის index.html ფაილი Tailwind CSS CDN-ის გამოყენებით. თემაა: [შენი არჩეული თემა, მაგ: მოტივაციური ციტატების გენერატორი]. გვერდზე უნდა იყოს: სათაური, ბარათი ციტატისთვის, ღილაკი 'ახალი ციტატა', ღილაკი 'ფავორიტებში შენახვა' და ქვემოთ ცალკე სექცია შენახული ციტატებისთვის. სტილი იყოს Dark Mode (slate-900 ფონით). JavaScript კოდი ცალკე script.js ფაილში უნდა იყოს გამოტანილი."*
