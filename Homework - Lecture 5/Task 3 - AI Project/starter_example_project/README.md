# 🌟 Daily Inspiration Hunter (AI Example Project)

ეს პროექტი შეიქმნა იმისთვის, რომ ნახო, როგორ გამოიყურება გამართული, AI-ს დახმარებით აწყობილი აპლიკაცია.

## 🚀 როგორ გავუშვათ:
- ორჯერ დააწკაპუნე `index.html` ფაილს და გახსენი ნებისმიერ ბრაუზერში.
- ინტერნეტთან კავშირის დროს ის მიმართავს DummyJSON API-ს, ხოლო თუ ინტერნეტი არ არის, ავტომატურად იყენებს ლოკალურ სარეზერვო ციტატებს.

## 💡 ფუნქციები:
1. **API Fetch**: `async/await` და `fetch()` იღებს ციტატებს სერვერიდან.
2. **DOM მანიპულაცია**: ციტატის ტექსტი და ავტორი დინამიურად იცვლება.
3. **შენახვა (State & Arrays)**: საყვარელი ციტატების მასივში დამატება.
4. **დინამიური ელემენტების წაშლა**: ფავორიტების სიიდან ნებისმიერი ციტატის ამოშლა.
5. **Tailwind CSS**: თანამედროვე Dark Mode დიზაინი გრადიენტებით.
