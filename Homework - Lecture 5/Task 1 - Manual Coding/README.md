# 🎯 დავალება 1: სურვილებისა და უნარების სია (Manual Coding)

## 📌 მიზანი
ეს დავალება შექმნილია იმისთვის, რომ **ხელით გაივარჯიშო** JavaScript-ის საბაზისო კონცეფციები:
- ცვლადები (`let` და `const`)
- DOM მანიპულაცია (`document.getElementById`, `document.createElement`, `innerHTML`, `classList`)
- მოვლენების მოსმენა (`addEventListener` — `click` და `keydown`)

---

## 📂 ფაილები ამ ფოლდერში:
1. **`test_working.html`** — სატესტო, სრულად გამართული ფაილი. გახსენი ბრაუზერში და შეამოწმე, როგორ უნდა მუშაობდეს საბოლოო შედეგი!
2. **`index.html`** — შენი სამუშაო HTML ფაილი (სტილები უკვე აწყობილია Tailwind CSS-ით).
3. **`script.js`** — შენი სამუშაო JavaScript ფაილი. აქ წერია დეტალური კომენტარები და TODO მინიშნებები.

---

## 📝 რა უნდა გააკეთო:
1. გახსენი `test_working.html` ბრაუზერში და გამოსცადე:
   - ტექსტის ჩაწერა და ღილაკზე დაჭერა
   - Enter ღილაკზე დაჭერა
   - მთვლელის მომატება / დაკლება
   - ნაგვის ურნაზე დაჭერით ელემენტის წაშლა
   - "ყველას გასუფთავება"
2. გახსენი `script.js` შენს კოდის ედიტორში (VS Code).
3. წაიკითხე კომენტარები და შეავსე `// TODO` ადგილები შენი ხელით.
4. გახსენი `index.html` და შეამოწმე, რომ შენი დაწერილი კოდი მუშაობს ისევე გამართულად, როგორც სატესტო ფაილი!
