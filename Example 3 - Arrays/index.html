🗂️ მასივები JavaScript-ში

Example 3 · TBC Tech School · Lecture 5

BASICS

მასივის შექმნა და ელემენტებზე წვდომა

მასივი ინახავს მონაცემების სიას ინდექსებით (0-დან).

const fruits = ["ვაშლი", "ბანანი", "მანდარინი", "ყურძენი"];
fruits[0];       // "ვაშლი"
fruits.length;   // 4
METHODS

push / pop / shift / unshift

ელემენტების დამატება და წაშლა მასივის დასაწყისიდან/ბოლოდან.

fruits.push("ნარინჯი");   // ბოლოს დამატება
fruits.pop();              // ბოლოს წაშლა
fruits.unshift("ლიმონი"); // დასაწყისში დამატება
fruits.shift();            // დასაწყისიდან წაშლა
ITERATION

forEach – ყოველ ელემენტზე

forEach ყოველ ელემენტს გადის თანმიმდევრულად.

const numbers = [1, 2, 3, 4, 5];
numbers.forEach(num => {
  console.log("რიცხვი:", num);
});
MAP

map – გარდაქმნა

ქმნის ახალ მასივს, სადაც ყოველი ელემენტი გარდაქმნილია.

const doubled = numbers.map(n => n * 2);
// [2, 4, 6, 8, 10]
FILTER

filter – გაფილტვრა

ქმნის ახალ მასივს მხოლოდ პირობის შემსრულებელი ელემენტებით.

const scores = [45, 82, 60, 91, 38, 75];
const passed = scores.filter(s => s >= 60);
// [82, 60, 91, 75]
FIND & INCLUDES

find / includes / indexOf

ელემენტის ძიება მასივში.

const students = ["ანა", "გიორგი", "ნინო", "დავით"];
students.includes("ნინო");             // true
students.indexOf("გიორგი");           // 1
students.find(s => s.startsWith("დ")); // "დავით"
