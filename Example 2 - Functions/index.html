⚙️ ფუნქციები JavaScript-ში

Example 2 · TBC Tech School · Lecture 5

1. Function Declaration

კლასიკური გამოცხადება. შეიძლება გამოძახება გამოცხადებამდეც.

function greet(name) {
  return "გამარჯობა, " + name;
}

2. Function Expression

ფუნქცია ცვლადში. გამოძახება მხოლოდ გამოცხადების შემდეგ.

const add = function(a, b) {
  return a + b;
};

3. Arrow Function ➜

მოკლე, თანამედროვე სინტაქსი. ყველაზე პოპულარული.

const multiply = (a, b) => a * b;
const square   = n => n * n;

4. Default Parameters

თუ არგუმენტი არ გადაეცა, გამოიყენება ნაგულისხმევი მნიშვნელობა.

function welcome(name = "სტუმარი") {
  return "მოგესალმებით, " + name;
}

5. Callback ფუნქცია

ფუნქციები შეიძლება სხვა ფუნქციებს გადაეცეს არგუმენტად.

function doMath(a, b, operation) {
  return operation(a, b);
}
doMath(10, 5, add);

6. Template Literals

სტრიქონების ჩასმა backtick-ებით და ${"$"}{}-ით.

const name = "ნინო";
const age  = 17;
`სახელი: ${"{name}"}, ასაკი: ${"{age}"}`
